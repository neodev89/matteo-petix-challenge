# Next.js Project

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev 
# Fortemente RACCOMANDATO !!!!!!
# or
bun dev
```

## Important to run this project

If you cloned this project in your IDE you run it after build.
Command: after the repo cloned in you IDE you run `pnpm build`. When the process is finished you run the command post-build
`pnpm start`.
if you would test this app in Lighthouse remember you start this application with command post-build and open localhost in Chrome browser
incognito tab.

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
